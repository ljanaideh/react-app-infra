Step-by-Step Flow

1

Developer pushes .tf changes

git push to a feature branch on GitHub

2

Open Pull Request

GitHub sends webhook to Atlantis via ngrok

3

Atlantis runs terraform plan

Posts plan output as a comment on the PR

4

Review the plan

Team reviews what will be created/changed/destroyed

5

Comment: atlantis apply

Atlantis runs terraform apply, creates AWS resources

6

Merge PR

Infrastructure is live, change is in git history

7

Push app code to main

GitHub Actions builds Docker image for ARM

8

Image pushed to ECR

EC2 pulls and runs the container on port 80

Key Commands

Deploy Infrastructure (via Atlantis)

git checkout -b feature-branch
# edit .tf files
git add . && git commit -m "add feature"
git push origin feature-branch
# Open PR on GitHub
# Atlantis auto-runs: terraform plan
# Comment on PR: atlantis apply -p dev

Build & Push Docker Image

cd app/
docker buildx build --platform linux/arm64 -t react-app-dev --load .
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
docker tag react-app-dev:latest $ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin $ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com
docker push $ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest

Cleanup (destroy everything)

cd environments/dev && terraform destroy
aws s3 rb s3://react-app-tfstate-laith --force
aws dynamodb delete-table --table-name terraform-locks --region us-east-1
