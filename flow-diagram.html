React App Infrastructure

Terraform • Atlantis • GitHub • ngrok • Docker • AWS EC2

Tools & Roles

⚙

Terraform

Defines AWS resources as code. Modules for VPC, ECR, and EC2.

🤖

Atlantis

Runs locally via Docker. Executes plan/apply on GitHub PRs.

🔌

ngrok

Tunnels localhost:4141 to a public URL so GitHub webhooks can reach Atlantis.

🐙

GitHub

Source of truth. All changes go through pull requests. Webhooks notify Atlantis.

🐳

Docker

Packages React app into a container. Pushed to ECR, pulled by EC2 on boot.

Setup Steps

1

Create GitHub Repo

Create react-app-infra on GitHub. Push Terraform modules, environment config, and React app.

2

Create S3 Backend & DynamoDB Lock Table

One-time manual setup for Terraform state storage.

aws s3 mb s3://react-app-tfstate-laith --region us-east-1 aws dynamodb create-table --table-name terraform-locks \ --attribute-definitions AttributeName=LockID,AttributeType=S \ --key-schema AttributeName=LockID,KeyType=HASH \ --billing-mode PAY_PER_REQUEST --region us-east-1
3

Start ngrok Tunnel

Expose your local port 4141 to the internet so GitHub can reach Atlantis.

ngrok http 4141 # Copy the https://xxxx.ngrok-free.dev URL
4

Start Atlantis (Docker)

Run Atlantis container with GitHub token, AWS credentials, and ngrok URL.

docker run -d --name atlantis -p 4141:4141 \ -e ATLANTIS_GH_USER="ljanaideh" \ -e ATLANTIS_GH_TOKEN="ghp_xxx" \ -e ATLANTIS_ATLANTIS_URL="https://xxx.ngrok-free.dev" \ -e AWS_ACCESS_KEY_ID="xxx" \ -e AWS_SECRET_ACCESS_KEY="xxx" \ -e AWS_REGION="us-east-1" \ ghcr.io/runatlantis/atlantis:latest server
5

Configure GitHub Webhook

Payload URL: https://xxx.ngrok-free.dev/events. Events: Pull requests, Issue comments, Push.

6

Open PR → Atlantis Plans Automatically

Push a branch, open a PR. GitHub sends webhook → ngrok tunnels to Atlantis → Atlantis runs terraform plan → posts result as PR comment.

git checkout -b feature-branch git push origin feature-branch # Open PR on GitHub → Atlantis comments with plan
7

Apply → Infrastructure Created

Comment atlantis apply -p dev → GitHub webhook → ngrok → Atlantis → terraform apply → VPC, ECR, EC2 created in AWS.

8

Build Docker Image (ARM) → Push to ECR

Build the React app for ARM architecture and push to ECR.

cd app/ docker buildx build --platform linux/arm64 -t react-app-dev --load . docker tag react-app-dev $ACCOUNT.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest docker push $ACCOUNT.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest
9

React App Live!

EC2 boots, pulls image from ECR, runs Docker container, serves React app on port 80.

http://<EC2_PUBLIC_IP>

Cleanup

1. Destroy Infrastructure

Remove all AWS resources

cd environments/dev terraform destroy

2. Delete State Backend

Remove S3 bucket & DynamoDB

aws s3 rb s3://react-app-tfstate-laith --force aws dynamodb delete-table \ --table-name terraform-locks \ --region us-east-1

3. Stop Local Services

Stop Atlantis, ngrok

docker stop atlantis docker rm atlantis # Ctrl+C ngrok
