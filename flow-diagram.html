React App Infrastructure

Terraform + Atlantis + GitHub + EC2 — Complete GitOps Workflow

Tools & Their Roles

Terraform

Defines AWS resources as code. Modules for VPC, ECR, and EC2 describe the infrastructure declaratively.

Atlantis

Runs on your laptop via Docker + ngrok. Listens for GitHub webhooks and executes terraform plan/apply on PRs.

GitHub

Source of truth. All infrastructure changes go through pull requests. Webhooks notify Atlantis of PR events.

Docker

Packages the React app into a container image. Pushed to ECR, pulled by EC2 on boot.

Step-by-Step Setup

1

Create GitHub Repo

Create react-app-infra on GitHub. Push Terraform modules, environment config, and React app.

2

Create AWS Backend (S3 + DynamoDB)

One-time manual setup for Terraform state storage.

aws s3 mb s3://react-app-tfstate-laith --region us-east-1 aws dynamodb create-table --table-name terraform-locks \ --attribute-definitions AttributeName=LockID,AttributeType=S \ --key-schema AttributeName=LockID,KeyType=HASH \ --billing-mode PAY_PER_REQUEST --region us-east-1
3

Start ngrok + Atlantis

Run ngrok to tunnel port 4141. Start Atlantis Docker container with GitHub token and AWS credentials.

ngrok http 4141 docker run -d --name atlantis -p 4141:4141 \ -e ATLANTIS_GH_USER="ljanaideh" \ -e ATLANTIS_GH_TOKEN="ghp_xxx" \ -e AWS_ACCESS_KEY_ID="xxx" \ -e AWS_SECRET_ACCESS_KEY="xxx" \ ghcr.io/runatlantis/atlantis:latest server
4

Configure GitHub Webhook

Point webhook to https://ngrok-url/events. Events: Pull requests, Issue comments, Push.

5

Open PR → Atlantis Plans

Push a branch with .tf changes, open a PR. Atlantis auto-runs terraform plan and posts the result as a PR comment.

git checkout -b feature-branch # make changes git push origin feature-branch # Open PR on GitHub
6

Comment "atlantis apply" → Infrastructure Created

Review the plan, then comment atlantis apply -p dev. Terraform creates VPC, ECR, EC2 in AWS.

7

Build Docker Image (ARM) → Push to ECR

Build the React app as an ARM container and push to ECR.

cd app/ docker buildx build --platform linux/arm64 -t react-app-dev --load . docker tag react-app-dev:latest ACCOUNT.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest docker push ACCOUNT.dkr.ecr.us-east-1.amazonaws.com/react-app-dev:latest
8

React App Live!

EC2 boots, pulls Docker image from ECR, serves React app on port 80. Access via public IP.

http://<EC2_PUBLIC_IP>
